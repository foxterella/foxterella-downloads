# Foxterella Suite — downloads

Installers for the **Foxterella Suite** by **Agri-Tech Organics (PNG) Limited**: Foxterella (dashboard), Mail, Write, Sheets, Slides and Connect, for Windows 10/11 and macOS 11+.

**Get started at [atopng.com/office](https://atopng.com/office/).** There you can download the apps, start a 7-day free trial, buy licences (K10 per user per month, or save 5% yearly) and register a domain for your business email.

The installers are attached to each [release](https://github.com/foxterella/foxterella-downloads/releases/latest).

- **Windows:** `Foxterella-<App>-Setup-<version>.exe`. If SmartScreen appears, choose *More info → Run anyway*.
- **Mac (Apple silicon and Intel):** `Foxterella-<App>-<version>-mac.dmg`. The first time you open an app, right-click it and choose *Open*.
